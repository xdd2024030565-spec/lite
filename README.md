## 备忘录（index.html · 备忘录页签）

移植自完整版的线上备忘录，**与完整版共享同一份云端数据**（同一个 vault-sync 地址与 token），
手机/电脑/两个站点之间互通。同样按兼容版约束实现：**纯 ES5**、同步用 `XMLHttpRequest`。

### 功能

- 新建 / 编辑 / 删除（进回收站）/ 恢复 / 彻底删除
- 置顶、分类（文件夹）、标签、标题正文全文搜索
- **⬆ 上传云端**：先拉取合并再整体写回（避免覆盖另一台设备的改动）
- **⬇ 从云端拉取**：按 id 合并，同一条取 `updatedAt` 较新的
- 导出 / 导入 JSON（用文本框，不依赖 Blob / File API）
- 同步设置：可自定义云端地址与口令
- 本地优先：所有内容先存 `localStorage`，断网也能用

### 与完整版的差异

不做内联实时编辑（改为表单编辑）、不做登录鉴权（兼容版本本身无登录）、
不做文件夹/标签下拉筛选（用全文搜索代替）。

### 云端

`https://vault-sync.yongjiu.ccwu.cc/memo/<token>`，CORS 白名单需包含本站域名，
否则浏览器会**静默失败**（见 lite1 仓库 `worker/wrangler.toml` 的 `ALLOW_ORIGIN`）。

## AI 助手（ai.html · 兼容版）

移植自完整版 [lite1](https://github.com/xdd2024030565-spec/lite1) 的 `ai.html`，按兼容版约束**重写**：
**纯 ES5**（无 const/let/箭头函数/Promise/fetch/模板字符串），老设备与内嵌 WebView 可直接跑。

### 保留的功能（直接可用的部分）

- **多提供商**：DeepSeek 网页版（内置免密钥）、任意 OpenAI 兼容接口
- **流式对话**：用 `XMLHttpRequest` 的 `readyState===3` 增量读取，不需要 `fetch`
- **多会话**：列表 / 新建 / 改名（点标题）/ 清空 / 删除
- **消息操作**：复制 / 重试 / 编辑重发 / 删除
- **Markdown 精简渲染**：粗体、斜体、行内代码、代码块、链接、列表（先转义再渲染，防注入）
- **设置**：温度 / 最大 Tokens / 流式开关；配置导出导入（文本框形式，老浏览器无 Blob 也能用）
- **主题**：亮 / 暗切换，与 `reader.html` 同一套配色
- **网络健壮性**：请求超时（非流式 60s / 流式 180s）、错误分类提示（超时 / 网络错误 / HTTP 码）

### 刻意去掉的部分

MCP、OpenAPI 插件、能力市场、工具调用（function calling）、上下文自动压缩、多账号池、
Promise/async 请求管线 —— 这些要么依赖现代语法，要么在电子墨水屏上收益极低。

### 书源（legado 书源直读，2026-10-30 重写）
网页端直接读取 **阅读（legado）格式的书源 JSON**，不需要安装 App、不需要自建后端解析规则——
规则在浏览器里用 DOM + XPath 求值，抓取走 `reader.yongjiu.ccwu.cc` 代理（解决跨域，并在服务端把 GBK 转成 UTF-8）。

**已实现的规则语法**（对齐 legado 实现）

| 语法 | 说明 |
|---|---|
| `class.x` / `id.x` / `tag.x` / `.x` / `#x` / 裸 CSS | 选择器简写 |
| `//XPath` | XPath，谓词里的 `@` 不会被当成步骤分隔符 |
| `.N` / `!N` | 取第 N 个 / **排除**第 N 个（0 基） |
| `children[n]` | 直接子节点 |
| `@text` `@textNodes` `@ownText` `@html` `@all` | 取值动作 |
| `@href` `@src` `@alt` `@title` `@content` `@<任意属性>` | 取属性（非动作词一律按属性名处理） |
| `##正则` `##正则##替换` `##正则##替换###` | 净化 / 全部替换 / **只替换首个**（`###` 是尾标记，与 legado 一致） |
| `##^##前缀` `##$##后缀` | 前后缀拼接 |
| `&&` / `\|\|` | 依次拼接 / 取首个非空（括号内不切分） |
| `searchUrl,{'method':'POST','body':…,'charset':'gbk','headers':{…}}` | 请求选项（POST / 请求体 / 编码 / 头），由代理在上游发出 |
| `$.a.b` `$.a[*]` `$.a[0]` `$..key` | JSON 接口书源的 JSONPath 子集 |

**不支持**：`<js>` 与 `@js:` 规则——它们依赖阅读 App 的 Java 桥（`java.ajax`、`cookie`、`source.getKey()` 等），
浏览器无法执行。这类书源会被**自动识别并跳过**，在书源管理里标注「需 JS」，可一键移除。

**搜索策略**：书源动辄上千个，不可能每轮全试。每轮按「结构完整度（可用 > 规则不全）→ 历史健康度」排序，
默认只试前 60 个（可在书源管理里调整上限）；每个源 10 秒超时、8 路并发，命中情况会累积到本地健康度，
下次优先试更可能成功的源。完成后会列出「未命中书源」的原因分布（规则未命中 / 超时 / HTTP 错误）。

**书源管理**：显示 `可用 / 需 JS / 规则不全` 分类计数，支持「只看可用」「一键移除需 JS 的源」，
书源列表超过 200 条时只渲染前 200 条（分页加载），避免上千条 DOM 卡顿。

> 实测（3907 个全量书源包里取前 80 个）：56 个可用 / 20 个需 JS / 4 个规则不全；
> 搜「斗破苍穹」20 秒得 102 条结果，打开后解析出 78 章目录，首章正文 2303 字。


- 交互（2026-10-25 起）：**点击正文中间 → 顶栏与底栏一起弹出/收起**（3.5 秒无操作自动收起，键盘 `T` 同效）；点击左 30% 翻上页、右 30% 翻下页；滑动翻页
- 只有**两层**界面元素：顶部工具栏（书库 / 章节标题 / 目录 / 设置）和底部工具栏（进度滑杆 + 上一页 / 进度 / 下一页），原先的右侧 `⋮` 导轨、居中圆钮菜单、左右 `‹ ›` 角标已全部移除
- 默认全屏阅读：两栏藏在屏幕外，正文不再被任何常驻栏遮挡
- 目录为右侧滑入抽屉（章节搜索 + 当前章高亮，Esc 关闭）；阅读设置为底部面板
- 5 种翻页动画：无 / 淡化 / 滑动 / 覆盖 / 仿真（`prefers-reduced-motion` 下关闭）
- 阅读设置精简为「翻页 / 排版 / 外观」三组，去掉了与新交互冲突的旧项（点按分区、顶部工具栏常显、底部按钮常显）
- 保持 ES5 兼容，纯 HTML + 内联脚本，无需构建
- 打开书籍时若版面尚未就绪（视口/键盘动画中），会自动重试排版，不再出现整本白屏

## 折叠组
兼容版已支持与完整版同构的折叠组：折叠时显示 favicon 横向堆叠 + 组内网址总数角标，与普通网址行同样大小、同样对齐；点击整行原地向下展开为折叠条 + 组内网址列表，再点顶部折叠条收起（带高度过渡，`prefers-reduced-motion` 时不做动画）。

- 折叠状态只存在内存里，刷新页面自动全部折叠
- 展开时组名右侧带「改名 / 解散」，旧浏览器也保留这两个入口
- 搜索命中组内的网址时，该组自动展开
- 添加面板与编辑面板都有折叠组选择，可「＋ 新建折叠组…」就地建组；编辑面板切换分类时折叠组自动联动
- 折叠组在列表中的位置由组内最新一条网址决定

## 静态快照
脚本不可用时（老设备 / 关闭 JS）页面直接用内嵌的静态快照渲染，样式与主页面一致，折叠组会以「折叠条 + 组内网址」的展开形式列出。

重新生成快照（读取线上 links.json，写入内联数据与静态列表）：

```bash
# 默认读 https://api.yongjiu.ccwu.cc 上的 links.json
python3 tools/gen_static.py

# 或用本地/已导出的 JSON
python3 tools/gen_static.py ./links.json
```

仓库内不放 links.json 副本，进仓库的只有生成后的 index.html。
